# 05 · Architecture and API

## Principles
1. The LLM never does math; SymPy decides every answer.
2. The server owns hint levels, attempts, the Teach state machine, outcomes and stars.
3. Templates first (en/es/vi); the LLM is optional and fails silently to templates.
4. Deterministic mock mode with no key or `MOCK_MODE=1`.
5. The LLM is called only per captured photo (plus an optional error-step call) and for free-form explanations.
6. No truth fields to the client. Minimal data; opt-in SQLite whitelist only.

## Stack
Frontend: React 19, Vite 6, TypeScript, Tailwind 4, framer-motion, canvas-confetti, Web Speech API, MediaPipe tasks-vision, qrcode.react, socket.io-client. Backend: Python 3.11+, FastAPI, Uvicorn, Pydantic v2, python-socketio, SymPy, google-genai, stdlib sqlite3. Tests: pytest; `npm run build` type-checks. Deploy: Vercel (frontend), Render/Railway (backend); CI in `.github/workflows/ci.yml`.

## Session state (in memory, lost on restart)
- `Session`: `problems {expr: ProblemState}`, `events`, `last_grade`, `last_fixed`, `teach`, `lumi_mastery {concept: 0..3}`, `teach_quotes {concept: (quality, text)}`, `town_visits`, `profile_id`, `saved_ready`.
- `ProblemState`: `attempts`, `hint_level`, `ever_wrong`, `fixed`, `concept`.
- `TeachState`: `worksheet_id`, `problems`, `review`, `queue`, `current`, `done`, `last_turn`, `demo`, `started`.
- `TeachProblem`: truth (`correct_answer`, `planted`, `concept`), child data (`outcome`, `child_fix`, `quote`, `found`), and the stage `explain|fix|find|sure|demo|next` with counters `fix_tries, help_level, followups, incorrect, nudge, gain, role_switched`.
- Client ids: session = 6 base-36 chars in `sessionStorage["lumi-session"]`; profile = 32 hex in `localStorage["lumi-profile"]` (only after consent).

## API (all under `/api`)
| Endpoint | In → out |
|---|---|
| `GET /health` | `{ok, mode: gemini\|mock, model}` |
| `GET /samples` | `[{name, url}]`; files at `/api/samples/files/<name>` |
| `POST /session/{id}/reset` | wipe a session |
| `POST /frame/{id}?kind=frame\|capture` | JPEG push from any camera, relayed to viewers |
| `POST /grade` (multipart `image`, `session_id`) | `{session_id, hand_blocking, unreadable, problems[], fixed_ids, mock, llm_error}`; a problem = `{id, problem, child_answer, correct_answer, is_correct, answered, bbox, answer_bbox, error_step, error_bbox, confidence, needs_confirmation}`; boxes `[ymin,xmin,ymax,xmax]` 0–1000 |
| `POST /tutor` | `{session_id, language, action: react\|hint\|chat, problem_id, child_said, history}` → `{emotion, say, focus_problem_id, hint_level, attempts, revealed, practice_problem}` |
| `POST /report` | `{session_id, language}` → `{score, total, correct, fixed, hints_used, concepts, practice_problems, summary, events (no teach_*), teach?{taught, quotes, caught, planted, missed, false_alarms, explanations, note, demo}}` |
| `POST /teach/concepts` | `{session_id, language}` → `{concepts[{concept, label, stars, ready, gate: help\|warmup}]}` (all twelve) |
| `POST /teach/warmup` | `{session_id, language, concept}` → `{warmup_id, concept, say, problems[{id, problem, kind, visual}]}` (newer concepts only; 400 otherwise) |
| `POST /teach/warmup/check` | `{session_id, language, warmup_id, answers[2]}` → `{passed, results[2], say, emotion}`; 409 `stale_warmup` |
| `POST /teach/worksheet` | `{session_id, language, force, demo, concept?}` → `{ready, needs: help\|warmup\|null, demo, worksheet_id, problems[{id, problem, lumi_answer, kind, visual}], concepts, turn}`; 400 `unknown_concept`; 503 `generation_failed` |
| `POST /teach/turn` | `{session_id, language, worksheet_id, action: check\|fix\|find\|explain\|confirm\|next, marks[{id, mark: circle\|check\|none, correction}], problem_id, answer, child_said, chip_id, agree}` → TeachTurn; 409 `stale_worksheet` |
| `POST /teach/town`, `/teach/scene`, `/teach/story`, `/teach/story/scene` | see [03](03-lumis-town.md) |
| `POST /profile` | `{session_id, consent: true, consent_version}` → `{profile_id, summary}`; 400 `consent_required`, 409 `consent_outdated` |
| `POST /profile/attach` | `{session_id, profile_id}` → merge + attach; 404 if gone |
| `DELETE /profile/{32hex}` | delete now, detach live sessions |

**TeachTurn:** `{emotion, say, step: practice_first|mark|fix|help|find|explain|demo|sure|next|done, focus_problem_id, highlight_ids, chips[{id, text}], demo{problem, steps, answer, visual}, outcomes[{id, outcome}] (unfound misses omitted), mastery (all twelve), mastery_up, help_level, stats{caught, planted, false_alarms}, unlocks[{kind: place\|story, key, title, emoji}]}`. `kind` is `number | time | compare` (which keypad); `visual` is `ruler | shape | fractions | bars` data for `MathVisual`. Structured errors: `{"detail": {"code", "message"}}`.

## State machines
- **Help (client):** SLEEPING → WATCHING → (Check my work / Auto-snap) CAPTURING → THINKING → RESULT → WATCHING; 60 s idle → SLEEPING. Idle in Teach and Town.
- **Teach (server):** `mark --check--> queue`; `find --find--> fix` (nudges, 4th miss points); `fix --fix--> explain` (2nd miss → `help`, levels to 4); `explain --explain--> ask_why / point / retry / role switch / demo`; `demo --confirm--> apply gain → next`; `sure --confirm--> next`; `next --next--> next problem | done`. Mismatched actions repeat `last_turn`.
- **Frontend modes:** `welcome | teach | help | town`; TeachView kept mounted in town, reset on help/welcome.

## Saved progress
Table `profiles(id, created_at, updated_at, consent_version, consented_at, data)`. Whitelist `mastery, quotes, ready, town_visits, story` (chosen version per act, scenes seen). Merge keeps max stars, `concept` quotes over `procedure`, union of ready, max visits. Autosave after every worksheet, turn, scene and grade (no-op without consent; stops if the profile was deleted). `purge()` on create/attach. `CONSENT_VERSION` ("2026-10-27") must match in `store.py` and `api.ts`.

## Events
`graded`, `fixed`, `hint`, `child_said`, `capture_rejected`, `llm_error`; `teach_worksheet`, `teach_checked`, `teach_explained {concept, quality, source}` (never words), `teach_role_switch`, `teach_mastery_up {concept, gain, agree}`, `teach_done {caught, planted, elapsed_s, demo}`; `town_scene`. Logs (`lumi.*`, INFO) never include speech, photos or answer keys.

## Configuration
`GEMINI_API_KEY` (empty → mock; never commit `.env`), `MOCK_MODE=1`, `GEMINI_MODEL` (code default `gemini-2.5-flash`), `GEMINI_TIMEOUT` 25, `GEMINI_VISION_THINKING` `low`, `CORS_ORIGINS`, `LUMI_DB` (default `backend/data/lumi.db`), `SAMPLES_DIR`, `LUMI_ADMIN` (dev only: enables the admin portal); Vite `BACKEND_URL` (proxy, default `:8000`), `VITE_BACKEND_URL` (production). Free Gemini tier ≈ 20 requests/day/model, so demo in mock mode.
